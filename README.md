# RehabTrack

RehabTrack is a full-stack healthcare platform built with Django & Flutter. It features role-based access, personalized rehabilitation plans, appointment scheduling, and dynamic progress logging. Clinicians can manage patients, while patients can visualize their recovery via interactive graphs.

## Tech Stack
- **Backend**: Django, Django REST Framework, SQLite
- **Frontend**: Flutter, Provider, Dio, fl_chart

## Features
- Role-based Access (Admin, Clinician, Patient)
- Dashboard overviews
- Secure API endpoints with SimpleJWT
- Dynamic Assessment Metrics (Pain Level, Range of Motion)
- Real-time data visualization
